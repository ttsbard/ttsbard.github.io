TTSBard Quick Start

Install TTSBard for Windows, test your audio device, choose a voice and speak your first phrase.

1. Install TTSBard

Open the latest release, download the Windows x64 installer from Assets (the file ending in _x64-setup.exe), run it, and open TTSBard.

Download for Windows

2. Choose and test your audio output

Open Audio → Devices. Turn on Speaker, select your headphones or speakers by name, and click ▶ Test playback. Check that the sound comes through the intended output.

Selecting a device by name keeps speech on that output and lets TTSBard reuse the stream between phrases. With (default), TTSBard checks the Windows output and opens a new stream for each phrase. A fixed output also helps when you want to keep speech separate from 5.1 or 7.1 game audio.

Send speech to Discord, OBS or a game

If you don’t have a virtual cable, download VB-CABLE from VB-Audio, extract the archive, run the installer as administrator, and restart Windows.

Under Audio → Devices → Virtual microphone, enable the output and select CABLE Input. In the receiving app, choose CABLE Output as its microphone. Click ▶ next to the virtual microphone in TTSBard and check that the receiving app’s meter responds.

3. Set up a voice

Choose a voice in TTS. For local voice cloning, set up Pocket TTS. To use a ready-made voice through Telegram, set up Silero.

Clone a voice with Pocket TTS

  1. Open Settings → Models. If the list is empty, click Download catalog from repository. Download Shtorm RU v2 Fast for Russian (about 600 MB) or Kyutai English for English (about 380 MB). Each model speaks only its own language.
  2. Open TTS → Pocket TTS and select the downloaded model. Choose a clean WAV recording of one speaker saying a complete phrase, ideally 5–8 seconds long and at most 12 seconds. Listen to it, then click Normalize.
  3. Make the model active and speak a short phrase in its language. On longer phrases, the model can start to stumble.

For Russian, install RUAccent in Settings → Models and turn on Place stresses automatically. More about preparing your WAV recording.

Use a Silero voice via Telegram

Open TTS → Silero, sign in to Telegram, choose a voice, and make Silero active. If the bot’s replies aren’t already in MP3, send /mp3 in the Telegram chat with @silero_voice_bot.

Setup guides for the other providers

4. Speak your first phrase

Open Text, select Voice only, type a short phrase in your selected voice’s language, such as “Voice test” or “Проверка голоса”, and press Speak or Enter. Check that you hear it on the intended output. From another app, press Ctrl+Shift+F3 to bring back the editor.

More ways to use TTSBard

  • Set up the quick editor for gaming or work.
  • OCR. Download a model in Settings → Models, then enable OCR in its panel to capture text from the screen.
  • Hotkeys. Change shortcuts in Hotkeys or assign an action to a single key in Key interception.
  • Compact and Mono. Press Ctrl+M for a smaller window. Use the editor’s … menu and choose Switch to Mono mode to keep only the text field.
  • Integrations. Display phrases in OBS or send them to Twitch chat or the VRChat chatbox. Set up integrations.
